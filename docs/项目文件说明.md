# 项目文件说明

本文是简历匹配平台的快速导览。接口字段、状态值和环境变量以代码与
`contracts/` 下的版本化契约为准；本文只说明文件职责，不替代契约。

## 根目录

| 文件或目录 | 用途 |
| --- | --- |
| `README.md` | 项目级本地启动、配置、构建、测试和受控联调说明。 |
| `.env.example` | 本地环境变量模板；复制为 `.env` 后填写授权凭据，不能提交真实密钥。 |
| `docker-compose.redis.yml` | 仅启动 Redis 本地依赖的 Docker Compose 定义。 |
| `database/` | 可选的 MySQL 手工建表快照；不替代 Java 服务使用的 Flyway 迁移。 |
| `front/` | Vue 3 + TypeScript 用户界面。 |
| `back/java/` | Spring Boot 公共 API、认证、权限、持久化和任务编排。 |
| `back/python/` | FastAPI 内部分析服务，负责解析、脱敏、匹配和模型调用。 |
| `contracts/` | Java、Python、Vue 共同使用的 OpenAPI、JSON Schema 和测试样例。 |
| `tests/integration/` | 跨服务离线断言、受控联调脚本和输入样例。 |
| `docs/` | 架构设计、实施计划、验证记录和本文件。 |

## Java 后端 `back/java/`

| 路径 | 用途 |
| --- | --- |
| `pom.xml` | Maven 依赖、Java 21 编译配置和测试配置。 |
| `mvnw` / `mvnw.cmd` | Maven Wrapper；在没有全局 Maven 时也能复现构建。 |
| `.../ResumePlatformApiApplication.java` | Spring Boot 启动类。 |
| `.../auth/` | 用户注册、登录、JWT、角色和认证错误处理。 |
| `.../profiles/` | 每用户 OpenAI 兼容模型配置、密钥加密调用和连接测试。 |
| `.../resumes/` | 简历上传、可见性状态、7/30 天归档、软删除、恢复和 Redis 页面缓存。 |
| `.../matching/` | 匹配任务、Python 内部调用、回调幂等、证据校验和结果持久化。 |
| `.../crypto/AesGcmCryptoService.java` | API 密钥等敏感值的 AES-GCM 加密与解密。 |
| `.../config/` | Spring Security、Redis、时钟和内部服务认证配置。 |
| `src/main/resources/application*.yml` | 默认与本地环境配置；敏感值通过环境变量注入。 |
| `src/main/resources/db/migration/` | Flyway 数据库迁移，建立用户、简历、任务、结果和审计表。 |
| `src/test/java/` | 认证、权限、生命周期、回调、加密和边界测试。 |

## Python 分析服务 `back/python/`

| 路径 | 用途 |
| --- | --- |
| `pyproject.toml` | Python 3.11 依赖和测试配置。 |
| `app/main.py` | FastAPI 健康检查和内部分析任务入口。 |
| `app/models.py` | 内部任务、回调和模型结构化输出的数据模型。 |
| `app/extraction.py` | TXT/DOCX 文本提取；不支持 PDF。 |
| `app/redaction.py` | 在外部模型调用前识别并脱敏个人信息。 |
| `app/matching.py` | 固定权重的可解释匹配评分。 |
| `app/analysis_service.py` | 组织提取、脱敏、证据绑定、模型调用和回调数据。 |
| `app/openai_compatible.py` | 用户自定义 OpenAI 兼容接口的请求和结构化响应校验。 |
| `app/callback_client.py` | 向 Java 回调结果并按规则处理重试。 |
| `app/settings.py` | 内部服务令牌、回调地址和运行参数。 |
| `tests/` | 脱敏、解析、评分、模型失败、回调和安全回归测试。 |

## 常用入口

1. 先读 `README.md` 了解本地环境和启动方式。
2. 要改接口或状态，先读 `contracts/README.md` 和对应 schema。
3. 要改业务生命周期，查看 `back/java/.../resumes/`、Flyway migration 和前端恢复页面。
4. 要改模型调用，查看 `back/java/.../profiles/`、`back/python/app/openai_compatible.py` 和脱敏测试。
5. 完成改动后，运行前端测试与构建，再按 `docs/verification/mvp-evidence.md` 区分离线证据和真实联调证据。
